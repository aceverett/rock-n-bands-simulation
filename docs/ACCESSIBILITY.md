# Accessibility Statement

Rock'n Bands targets WCAG 2.2 Level AA. The application uses semantic landmarks, one page-level heading per view, a skip link, native form controls and dialogs, visible focus, keyboard-complete interactions, specific validation, an error summary, concise live updates, and text/icon labels in addition to color.

The layout supports reflow at 320 CSS pixels and text enlargement to 200%. Allocation targets are approximately 44 CSS pixels. Network information is available both as inline SVG and as a complete text table. No information depends on sound, motion, dragging, orientation, or a time limit. Reduced-motion and forced-colors preferences receive explicit styling. Printable and downloadable results remain understandable without color.

Known environmental limitation: iframe embedding and “Return to Canvas” behavior depend on institutional Canvas and browser security policies. An external-link fallback is documented. The standalone version cannot synchronize saves across devices because it intentionally sends no learner data to a server.

Automated axe-core results supplement, but do not replace, the manual checklist in `docs/ACCESSIBILITY_QA.md`.
